Luna’s Kitchen 🍽️
A responsive, multi-page restaurant website built as a front-end development learning and portfolio project.
About the Project
Luna’s Kitchen is a fictional restaurant website created to practice front-end web development. The project focuses on building a consistent visual design across multiple pages and creating a layout that adapts to different screen sizes.
Pages
Home (index.html) — The main landing page.
Menu (menu.html) — Displays the restaurant’s menu and meal deals.
About (about.html) — Introduces the restaurant concept.
Contact (contact.html) — Includes contact information for demonstration purposes and a sample contact form.
Technologies Used
HTML5
CSS3
Bootstrap 5
Features
Responsive layout for different screen sizes.
Four interconnected website pages.
Consistent navigation across pages.
Custom styling with a black and blush-pink color palette.
CSS animations and hover effects.
Contact form interface for demonstration purposes.
